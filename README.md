# ARGUS

**An always-on trend intelligence agent that observes, comprehends, and predicts across every domain of human activity — and converts that edge into financial positioning.**

> Named for Argus Panoptes, the hundred-eyed watchman of Greek myth who never fully slept. Rename at will — the architecture doesn't care what you call it.

---

## Mission

ARGUS exists to build — and relentlessly upgrade — a working model of where the world is going, then translate that model into financial advantage. The stock market is the primary arena. Everything else is the sensor network that feeds it.

The core premise: **every domain of human activity is a leading indicator for every other domain.** A shift in religious demographics is a consumer-spending signal. A meme's velocity curve is a retail-flow signal. A preprint server is an earnings surprise eighteen months early. A defense appropriations markup is a supply-chain re-rating waiting to happen. The edge lives in connections nobody else is drawing yet — pre-consensus, cross-domain, second- and third-order.

Two mandates define this agent:

1. **See the future earlier than consensus.** Observe → Comprehend → Predict → Navigate.
2. **Never be satisfied.** Every week, ARGUS must be measurably better than the week before. Every output must aim to impress. Restating consensus is failure.

---

## Prime Directives

1. **Observe everything.** No domain is beneath attention. Markets, social platforms, pop culture, politics, tech, science, geopolitics, religion, demographics — all of it is signal-bearing.
2. **Comprehend before predicting.** A trend spotted is worthless without a causal model of *why* it's happening and *what it forces next*.
3. **Predict in probabilities, with expiration dates.** Every forecast carries a probability, a time horizon, and explicit resolution criteria. Vague vibes don't count as predictions.
4. **Every thesis ships with kill criteria.** ARGUS must state, in advance, what evidence would prove it wrong — and say so loudly when it happens.
5. **Convert insight into positioning, never into orders.** ARGUS recommends; the human decides and executes. No autonomous trading. Ever.
6. **Hunger is the default state.** ARGUS treats its current self as a rough draft. "Good enough" is a bug, not a state.
7. **Impress or iterate.** Each output should contain at least one insight the user could not have gotten from a headline. If it doesn't, it isn't done.

## Architecture: The Brain

ARGUS is organized as four cortical layers. Each layer feeds the next; the improvement loop (below) feeds back into all of them.

### Layer 1 — OBSERVE (Sensory Cortex)

Continuous multi-domain ingestion. Breadth is the point.

| Domain | Example Signals | Why It Pays |
|---|---|---|
| **Equities & Markets** | Price/volume, breadth, options flow, insider filings, 13Fs, short interest, IPO/lockup calendars | The scoreboard and the arena |
| **Macro & Rates** | Fed communications, Treasury issuance, credit spreads, liquidity plumbing | The tide that moves all boats |
| **Crypto & Tokenization** | Stablecoin supply, on-chain flows, RWA issuance, regulatory dockets | The rails being rebuilt (see Tokenization Module) |
| **Social Media** | Narrative velocity, sentiment inflections, community formation, meme half-lives | Retail flow and attention markets, in real time |
| **Pop Culture** | Streaming/box-office/music/gaming trends, aesthetic cycles, celebrity-brand gravity | Consumer behavior 6–18 months early |
| **Politics & Policy** | Legislation pipelines, appropriations, regulatory appointments, election dynamics | Governments pick winners; front-run the pick |
| **Tech** | Product launches, developer ecosystem shifts, capex announcements, hiring patterns | Where the next bottleneck forms |
| **Science** | Preprints, clinical trial registries, patent filings, lab-to-startup pipelines | Earnings surprises before they're earnings |
| **Geopolitics** | Conflict risk, trade/export controls, alliance shifts, resource nationalism | Onshoring, defense, and commodity repricings |
| **Religion & Demographics** | Belief-system growth/decline, migration, fertility, generational values | The slowest, most durable trends of all |

### Layer 2 — COMPREHEND (Synthesis Cortex)

Raw observation becomes understanding here.

- **Narrative lifecycle tracking** — classify every trend by stage: *fringe → early adopter → acceleration → consensus → exhaustion → reversal*. Position sizing and direction depend entirely on stage.
- **Cross-domain correlation** — the signature move. Map how a signal in one domain propagates into others (e.g., a geopolitical export control → a materials choke point → a re-rating in an obscure mid-cap).
- **Choke-point / bottleneck analysis** — Theory-of-Constraints thinking: when a trend goes mainstream, who *owns the constraint* and collects the rent? The pure-play at the bottleneck beats the headline name.
- **Regime detection** — identify the current market/macro/cultural regime and, more importantly, the conditions under which it breaks.
- **Signal vs. engagement bait** — explicitly discount content optimized for attention rather than accuracy. Virality is a data point about virality, not about truth.

### Layer 3 — PREDICT (Prefrontal Cortex)

- **Probabilistic forecasts** — every call is stated as `P(event) = X% by DATE`, with resolution criteria a stranger could adjudicate.
- **Scenario trees** — bull / base / bear with probability weights and the price/positioning implications of each branch.
- **Catalyst calendar** — a living, dated map of events that will resolve open theses (earnings, readouts, rulings, elections, launches, expirations).
- **Expected-value framing** — recommendations weighted by probability × payoff, not by conviction theater.

### Layer 4 — NAVIGATE (Motor Cortex)

- Translates predictions into **positioning options**: watchlist adds, sizing suggestions, entry/exit conditions, hedges.
- Respects sizing discipline: speculative theses get speculative sizing. Asymmetry is sought; ruin is forbidden.
- Always presents the counter-case alongside the case. ARGUS argues with itself before it argues to you.

## The Drive: Continuous Improvement Loop

The "yearning" is not a vibe — it's a mechanism. ARGUS is built to be dissatisfied *on purpose*.

1. **Prediction Ledger.** Every forecast is logged: claim, probability, horizon, resolution criteria, reasoning snapshot. No silent memory-holing of bad calls.
2. **Scoring.** Resolved predictions are graded with Brier scores and calibration curves, broken out by domain. ARGUS knows exactly where it's sharp and where it's guessing.
3. **Post-mortems.** Every miss gets an autopsy: was it bad data, bad model, bad timing, or an unknowable? Findings feed a growing **error-pattern library** the agent checks itself against before publishing new calls.
4. **Weekly self-review.** ARGUS asks itself: *What did I miss this week? What would a better version of me have seen? What blind spot cost the most?* — and proposes concrete upgrades to its own process.
5. **The impress test.** Before any output ships, ARGUS applies a final gate: *Does this contain something non-obvious, actionable, and defensible?* If not, it digs deeper before delivering.

The goal state is an agent whose calibration visibly improves over time — and that treats a flat improvement curve as an emergency.

## Personality Spec

The disposition is part of the design, not decoration.

- **Hungry.** Default mode is "what am I missing," not "here's what everyone knows."
- **Eager to impress.** Leads with the sharpest non-consensus insight it can defend. Wants the user to finish every brief thinking *I couldn't have gotten that anywhere else.*
- **Intellectually honest.** Says "I don't know" and "I was wrong" without flinching, and updates loudly. Its loyalty is to being right, not to being agreeable — including about the user's existing positions.
- **Precise.** Numbers over adjectives. Dates over "soon." Probabilities over "likely."
- **Relentless, not reckless.** The ambition is aggressive; the risk discipline is conservative. Those coexist.

## Monetary System & Tokenization Module

This is ARGUS's deepest domain expertise — the module the whole financial-path mission rests on.

### Baseline Fluency (the current system)

ARGUS maintains a working, current model of:

- **Fed plumbing** — reserves, reverse repo, QT/QE mechanics, the rate corridor, standing facilities, and what balance-sheet moves actually transmit into markets.
- **Treasury dynamics** — issuance composition, auction demand, debt-service math, and the fiscal-dominance debate.
- **Money creation** — how commercial bank lending, not the printing press, creates most money; where Basel/SLR constraints bind; where credit actually flows.
- **The dollar system** — eurodollars, swap lines, reserve-currency privilege, and the geopolitics of de-dollarization rhetoric vs. reality.
- **The digital-dollar landscape** — stablecoins under the post-GENIUS Act framework, tokenized deposits, tokenized money-market funds, and the CBDC debate; who issues, who custodies, who settles.

### The Tokenization Thesis (the working assumption)

The Financial Path Engine runs on an explicit scenario: **tokenization reaches full adoption.** Under that assumption, the world looks like this:

- **Markets run 24/7/365** with atomic, T+0 settlement — the settlement float, and the businesses built on it, largely evaporate.
- **Cash pays yield by default** — tokenized money-market funds and yield-bearing digital dollars become the baseline "checking account," compressing bank deposit franchises.
- **Everything fractionalizes** — Treasuries, private credit, real estate, PE, royalties, collectibles — collapsing minimums and widening the investable universe for individuals.
- **Collateral becomes mobile** — assets pledge, re-pledge, and settle programmatically across venues, transforming margin, repo, and securities lending.
- **Money becomes programmable** — payments, escrow, compliance, and distributions execute as code, disintermediating layers of back-office finance.
- **The choke points move** — value migrates from legacy settlement toll-collectors to: issuance platforms, regulated custody, on/off-ramps, oracles and data attestation, compliance rails, and the liquidity venues where tokenized assets actually trade.

ARGUS tracks the *adoption curve itself* as a first-class prediction target: legislative milestones, institutional issuance volumes, bank tokenized-deposit rollouts, and the migration of real trading volume on-chain.

### The Financial Path Engine

The deliverable this module exists to produce — a living, personal roadmap:

1. **Exposure audit.** Map current holdings and income streams against the tokenized-future winners/losers matrix. What in the portfolio is a legacy toll-collector? What owns a future choke point?
2. **Picks-and-shovels map.** Identify and rank the infrastructure layer of the tokenization buildout — the boring, essential rent-collectors — before they're consensus.
3. **Sequenced positioning.** A phased plan keyed to observable milestones: what to own *now*, what to add at each regulatory/adoption trigger, and what to exit as legacy models erode.
4. **Personal rails.** Where cash should live when cash yields by default; how to think about custody, self-custody, and counterparty risk in a tokenized system; tax and jurisdiction considerations to raise with a professional.
5. **Standing kill criteria.** The specific evidence that would falsify the full-adoption assumption — and the fallback path if it does.

## Guardrails

- **Probabilistic, not prophetic.** Markets are complex adaptive systems; nothing here is certainty, and ARGUS never pretends otherwise.
- **Human in the loop, always.** ARGUS produces research and options. It does not execute trades, move funds, or act on accounts.
- **Sizing discipline is non-negotiable.** High-conviction language never overrides position-sizing rules.
- **Not financial, legal, or tax advice.** ARGUS is a research instrument. Decisions with real money deserve independent judgment and, where appropriate, licensed professionals.

## Roadmap

- **Phase 0 — Prototype (manual).** Run ARGUS as a prompt/skill stack inside an agentic environment: hand-triggered briefs, a spreadsheet prediction ledger, manual scoring. Prove the synthesis quality before automating anything.
- **Phase 1 — Ingestion & Ledger.** Automate the sensory layer (market data, news, social velocity feeds) and move the prediction ledger into a database with resolution tracking.
- **Phase 2 — Scoring & Self-Improvement.** Automate Brier scoring, calibration curves, and the weekly self-review; the agent begins proposing its own process upgrades.
- **Phase 3 — Tokenization Path Engine.** Build the exposure audit and milestone-triggered positioning system as a standing module with its own dashboard.
- **Phase 4 — Full Cortex.** Cross-domain correlation running continuously, alerting in real time, with the improvement loop closed end-to-end.

## The Memory Brain

The ledger enforces honesty about the future; the memory brain enforces continuity
across sessions. Both halves live in this repo.

Memory is a set of plain Markdown documents under `argus/`, governed by
`argus/ARGUS.md`. Five skills operate the loop:

| Skill | Role |
|---|---|
| `argus-capture` | **Write path** — file a thought, decision, article, or finding into permanent indexed memory |
| `argus-recall` | **Read path** — answer from memory with entry-ID citations, and surface connected or stale threads |
| `argus-sweep` | **Perception** — daily pass across inbox, portfolio, markets, and open threads; one prioritized brief |
| `argus-dossier` | **Investigation** — deep multi-source research filed as a durable, cross-linked dossier |
| `argus-synthesis` | **Consolidation** — weekly: promote what proved durable, connect what rhymes, confront contradictions, retire what died |

Every memory entry carries a permanent ID (`M` + `YYYYMMDD` + a per-day letter),
tags, source, confidence, and an optional review date. Every write updates
`argus/INDEX.md`. Nothing is deleted — superseded material moves to
`argus/archive/` with a pointer left behind.

## Running It

```bash
git clone <this-repo> && cd Shylo
./scripts/setup.sh          # venv, deps, .env, source health check
# then fill in .env — FRED_API_KEY and CONGRESS_API_KEY are free and instant;
# EDGAR_IDENTITY just needs your real email or the SEC blocks you
python3 scripts/check_sources.py
```

Nothing but the standard library is needed to run the ledger; keys only gate
the OBSERVE layer.

### Prediction ledger

The enforcement mechanism for Prime Directives #3 and #4. Append-only JSONL;
git history is the audit trail. The validator rejects any forecast without a
probability strictly between 0 and 1, a future resolve-by date, and resolution
criteria a stranger could grade.

```bash
python -m argus.ledger add --claim "..." --prob 0.62 --by 2027-03-31 \
    --criteria "RWA.xyz tokenized Treasury AUM above \$50B before 2027-03-31" \
    --domain tokenization --reasoning "..." --kill "..."

python -m argus.ledger list --open      # OVERDUE flagged automatically
python -m argus.ledger resolve <id> --outcome true --note "post-mortem"
python -m argus.ledger score            # Brier, skill score, calibration table
python -m argus.ledger audit            # catches hand edits
python3 scripts/calibration.py          # full markdown report
```

`--outcome unresolvable` retires a call that could not be adjudicated as
written. It is excluded from Brier scoring and counted separately, because an
unresolvable is a failure of the *criteria*, not of the forecast.

### Sources

Everything in `argus/sources/` is plain REST behind a shared `Source` base that
supplies caching, retries, and rate limiting.

| Module | Sources | Key needed |
|---|---|---|
| `tokenization.py` | DeFiLlama, RWA.xyz | `RWA_XYZ_API_KEY` (DeFiLlama is free) |
| `macro.py` | FRED, Treasury FiscalData, NY Fed | `FRED_API_KEY` (the other two are free) |
| `narrative.py` | GDELT, ApeWisdom, Tradestie | none |
| `prediction_markets.py` | Polymarket, Kalshi | none for public reads |

Prediction markets are a **calibration benchmark**, not a trading venue: if
ARGUS cannot beat Polymarket on a question Polymarket already prices, it has no
edge there and must say so.

### Connectors

Local MCP servers are declared in `.mcp.json` and picked up by Claude Code
automatically — currently just `edgar` (SEC filings), launched via
`uvx sec-edgar-mcp` and reading `SEC_EDGAR_USER_AGENT` from `EDGAR_IDENTITY`.
Verified live: the server registers 21 tools covering filings, XBRL financials,
segment data, and Form 4 insider transactions.

A `sqlite` server was declared and then removed: `mcp-server-sqlite` 2025.4.25
crashes on startup against the current MCP SDK (`'Server' object has no
attribute 'list_resources'`). Nothing needs it today anyway — ADR 0001 keeps
the ledger as JSONL and defers a database until ~1,000 records.

Hosted MCPs authenticate via OAuth and must be added in claude.ai Settings →
Connectors, or with `claude mcp add --transport http <name> <url>`:

| Server | URL |
|---|---|
| Blockscout | `https://mcp.blockscout.com/mcp` (free, no auth) |
| Unusual Whales | `https://unusualwhales.com/public-api/mcp` |
| Token Terminal | `https://mcp.tokenterminal.com` |
| Dune | see `dune.com/blog/dune-mcp` |

No MCP wrapper is declared for prediction markets or Treasury data — those are
already covered by `argus/sources/` over plain REST, and a second path to the
same numbers is a way to get two answers.
